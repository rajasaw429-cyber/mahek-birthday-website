# Happy Birthday Mahek Darling

A romantic, tap-to-continue birthday website (16 pages) made with plain HTML, CSS and JavaScript. No frameworks, no build step, no music.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, then Save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Structure
- `index.html` - all 16 pages
- `css/style.css` - styles and animations
- `js/script.js` - page flow, canvas hearts, confetti, card game, letter
- `images/` - photos used on the pages

To edit the letter, search for `const LT` in `js/script.js`.
Fonts load from Google Fonts, so an internet connection is needed for the exact look.
